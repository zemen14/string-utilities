# String Utilities (C)

A small string-manipulation library in C, written from scratch on top of the standard library, with a test suite.

## What's inside

- **strings.c / strings.h** — functions for suffix checks, searching, comparison, and related string work.
- **strings_test.c** — unit tests for the library.

## Build & run

```sh
make            # builds strings_test
./strings_test
```

## Tech

C, Make
